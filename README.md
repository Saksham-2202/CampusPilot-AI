Vibe coding project from gemini canvas as a part of Represent India at Google's Edu on Air 2026

An AI-powered academic workspace designed to transform learning through multi-modal intelligence, interactive gamification, and automated study tools. Built to showcase the absolute bleeding edge of Google's Generative AI capabilities.

🌟 Key Features & Innovations

🌍 Global Multilingual Support

Native Language Processing: The entire suite of AI tools can process inputs and generate comprehensive outputs in multiple languages (e.g., Hindi, as seen in the demo), making advanced education technology accessible to a wider demographic in India and globally.

📸 Snap & Solve (Vision AI)

Photo to Breakdown: Leverages Gemini's vision capabilities. Users can upload images of complex diagrams, handwritten equations, or textbook pages, and the AI instantly breaks down the concepts into easily understandable notes and steps.

🎙️ Talk & Learn (Audio AI)

Voice to Notes: Allows users to interact with the platform verbally. It captures voice input and instantly transcribes and processes it into structured study notes or direct answers, facilitating hands-free learning.

🧠 Live Visual Mind Maps

Concept Mapping: Dynamically generates visual representations of complex topics, connecting core concepts and subtopics to help students grasp the "big picture" of their study materials instantly.

🛠️ The Complete AI Tool Suite

Study Assistant: Instant markdown summaries, exam tips, key formulas, and flashcard generation (with full multilingual output support).

Coding Assistant: Debugs, optimizes, and explains code across multiple programming languages.

Resume Assistant: ATS optimization, tailored formatting, and structural feedback.

Email Generator: Drafts professional emails for academic and career inquiries with adjustable tones.

Study Planner: Creates custom revision timetables and daily study strategies.

Presentation: Builds presentation outlines, slide structures, and speaker notes.

Interview Coach: Simulates mock technical and behavioral Q&A sessions with instant feedback.

Research Assistant: Deep dives into topics, surfacing key ideas and comprehensive overviews.

Snap & Solve: Photo → Instant Breakdown.

Talk & Learn: Voice → Instant Notes.

Mind Map: Live Visual Concept Maps.

💻 Tech Stack

Frontend Framework: React + Vite

Styling: Tailwind CSS (with robust custom Markdown rendering classes)

AI Orchestration: Google Gemini API (Text, Vision, and Multilingual processing)

Markdown Parsing: Marked.js + Custom CSS styling

🚀 Getting Started

Prerequisites

Node.js (v18 or higher)

A valid Google Gemini API Key

Installation

Clone the repository:

git clone https://github.com/your-username/campus-pilot-ai.git
cd campus-pilot-ai


Install dependencies:

npm install


Configure API Key:
Open src/lib/gemini.js and insert your API key:

const apiKey = "YOUR_GEMINI_API_KEY_HERE";


Run the development server:

npm run dev
